  1. Select Copy signature above.
  2. In the new Outlook, open Settings (the gear), then Accounts and Signatures. In Outlook on the web, open Settings, then Mail and Compose and reply.
  3. Select New signature and name it XBS.
  4. Click in the editing box and paste with Ctrl+V.
  5. Set this signature as the default for new messages and for replies and forwards, then Save.

  1. Select Copy signature above.
  2. In Outlook, open the Outlook menu, then Settings, then Signatures.
  3. Select + to add a signature and name it XBS.
  4. Click in the editing box and paste with Cmd+V.
  5. Set the default for new messages and for replies and forwards, then close the window.
